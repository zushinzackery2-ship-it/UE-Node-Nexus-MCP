# UE Node Nexus MCP v0.3.1

本次更新采用新的开环抽象标识，并同步到核心插件、VFX 插件、README 和发行包。

- 两侧不同尺度的弧面围合中心留白，表达本地结构的收拢与展开。
- 深石墨底、浅色与青绿色配色；提供透明标记和可着色的单色 SVG。
- 提供 16、32、64、128、256、512、1024 像素 PNG，完成小尺寸与明暗背景检查。
- 两个插件使用同一新版 Icon128.png，Python 与插件显示版本统一为 0.3.1。

本版保留 0.3.0 的操作与同步行为。插件源码、配置、图标和 DLL 由发布脚本校验，
附件附有 SHA256 与逐文件清单。

## 附件

| 文件 | 用途 |
|:-----|:-----|
| `UE-Node-Nexus-MCP-v0.3.1-UE5.5-Win64.zip` | 双插件、源码、新图标、安装说明和 Agent skill |
| `ue_node_nexus_mcp-0.3.1-py3-none-any.whl` | Python MCP 服务 |
| `SHA256SUMS.txt` | 附件 SHA256 校验值 |
| `release-manifest.json` | 源码提交、引擎版本及逐文件校验信息 |

关闭编辑器，将 ZIP 中的 `Plugins/` 合并到工程根目录，安装本版 Wheel 后重新启动。
目标环境为 UE 5.5.4 Launcher / Windows x64，模块 BuildId `37670630`。
