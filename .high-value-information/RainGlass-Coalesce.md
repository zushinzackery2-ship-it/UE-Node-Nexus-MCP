# 雨玻璃水珠吸引合体

单格 Heartfelt 会在格边裁掉水珠，相邻两颗永远碰不上。blog 的熔接来自 `c = S(0.3, 1, sum)`，前提是同一像素能看见两颗的场。

## 场

水平邻格 `id.x-1 / 0 / +1` 各算一颗中心（`MF_WS_DropPos`，公式仍是 DropLayer2 的 x/y）。

互拉（同时、对称，最多走到中点）：

```
d = length((pA - pB) * a.yx)
w = S(2.125R, 0.375R, d)
pA' = pA + (pB - pA) * w * 0.5
pB' = pB + (pA - pB) * w * 0.5
```

默认 R=0.4：间距 < 0.85 开始吸，< 0.15 贴死。三颗圆盘相加后仍走 `S(0.3,1,c)` 熔成一颗。

列珠仍加在本格吸引后的 x 上。湿痕带、水雾不进 3-tap。
