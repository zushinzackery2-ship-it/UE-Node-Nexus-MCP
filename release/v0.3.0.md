# UE Node Nexus MCP v0.3.0

本版将资产编辑接入本地 `.nexus` 文本镜像，并补齐同步失败保护和恢复流程。
发布包同时包含核心与 VFX 插件，Python 服务和两个插件的显示版本统一为 0.3.0。

## 更新内容

- 7 个 MCP 工具、132 个 operation；支持文本镜像初始化、状态、拉取、校验、推送与 schema 更新。
- 本地解码与文本差异提交，减少逐节点操作中的重复 JSON 传输与调用。
- 新资产按依赖顺序提交，覆盖组件属性和嵌套引用；依赖环及依赖失败明确报错。
- 推送失败保留本地编辑和旧基线，记录节点 ID 与恢复信息；强制重试依据实时 UE 状态重算。
- MF 调用者刷新保护本地编辑；dry-run 保持文本和同步状态；状态区分脏标记与磁盘变化。
- core/VFX 统一处理编译、保存失败和空计划脏包重试。
- 关卡 Actor/组件点路径属性写入、视口相机与截图改进、材质实例参数写入修复。
- 新 Nexus 图标已用于两个插件，README 与安装说明同步更新。

## 下载与安装

| 文件 | 用途 |
|:-----|:-----|
| `UE-Node-Nexus-MCP-v0.3.0-UE5.5-Win64.zip` | 核心与 VFX 插件的 DLL、源码、配置、新图标、Agent skill 和安装说明 |
| `ue_node_nexus_mcp-0.3.0-py3-none-any.whl` | Python MCP 服务 |
| `SHA256SUMS.txt` | 附件 SHA256 校验值 |
| `release-manifest.json` | 源码提交、引擎版本及逐文件校验信息 |

关闭编辑器，将 ZIP 中的 `Plugins/` 合并到工程根目录，再用 Python 3.11+ 安装 Wheel。
MCP 客户端启动 `.venv/Scripts/ue-node-nexus-mcp.exe`，完整步骤见包内 `INSTALL.md`。
