# 雨玻璃水珠吸引合体

> **现状：`合体强度` = 0，本文描述的吸引位移当前没开。**
> 三盘"不裁水珠"仍然在用且已修好（邻列走自己的行框）。
> 吸引位移的 y 是观察者相关的，会把同一颗珠在格边两侧放到不同高度，
> 落差达珠半高的 0.6~1.9 倍。开它之前先读 `RainGlass-CellSeams.md` 的机制 C。

单格 Heartfelt 会在格边裁掉水珠。水平邻格 `id.x±1` 各算一颗中心。

**跨列取邻居必须用邻列自己的 `colShift`**（`N(id.x±1)` → 自己的 `id.y` 和 `st.y`）。
用本列的 `id.y` 会画出邻列并不存在的幽灵珠，实测 38.6% 的采样行号不一致。

x 不随时间变。互拉只看水平距，贴上之后不再用竖直距把团拆开：

```
dx = |xA - xB|
w  = S(2.125R, 0.375R, dx)
```

x 锁到团心。y 按 `0.15 + Saw` 加权：正在滑的质量大，带着停着的走；停着的那 0.15 让动的略顿一下。三颗圆盘仍相加，`S(0.3,1,c)` 熔成一颗。

列珠加在本格锁后的 x 上。湿痕带、水雾不进 3-tap。
