# 雨玻璃软边（按水珠屏幕尺度）

固定 `S(R, 0, d)` 会让整颗圆盘都是过渡。大珠看起来正常；极小珠在屏幕上只有两三个像素时，这条边相对珠身会偏大。

## 公式

`MF_WS_SoftDisc(D, Radius, PixelWidth)`：

```
k = sat((PixelWidth / max(R, 1e-6)) * 1.2 - 0.25)
inner = R * k * 0.28
return S(R, inner, D)
```

**`PixelWidth` 由调用方传入，不在 SoftDisc 里求导。** 距离场的梯度模在自己度量下恒为 1，
所以一个度量算一次 footprint 就够（原先每个盘各求一次，每像素 75 对导数，现在 13 对）。
调用方必须对 **`frac` 之前**的网格坐标求导：`D` 依赖 `frac()`，直接对 `D` 求导会在每个
格边尖峰，把 `k` 从 0 顶到 1、`inner` 跳到 0.28R，留下 1~2px 硬边列。

```
footprint = length(float2(|DDX(g)|, |DDY(g)|)) / sqrt(2)
```

`g` 是该盘所用度量下的网格坐标：三颗主珠用 `g2 * a.yx`，珠串和水雾用未乘 `a.yx` 的。
`/sqrt(2)` 是为了在各向同性度量下与旧的 `length(float2(DDX(D),DDY(D)))` 数值相等
（本链 `grid * a.yx = (12,12)` 天然各向同性）。

- 大中珠：`w/R < 0.2` → `k=0` → `inner=0` → Heartfelt `S(R,0,d)`，整盘软肩
- 极小珠：`k→1` → `inner=0.28R` → 仍留约 72% 软肩，禁止收到只剩外圈 25%

「软边」参数仍是外半径 R，默认 0.4。列珠半径 `R*0.75`（默认 0.3）。水雾半径 0.3。

测试机位实测 `footprint = 0.0183`、`k = 0.000`——**这条自适应在近景根本不生效**，
只有远景小珠才激活。别把它当近景观感问题的抓手。

禁止 `DDX/DDY(WorldPosition)`。禁止直接对 `frac` 之后的量求导。
