# 雨玻璃抖动：已踩实的两条根因

视口「整面在抖」和「每一滴自己在抖」不是同一条 bug。两条都有离线探针数，修完后主人确认不抖。禁止把它们混成「PNO 太强」再去改折射公式。

探针脚本在 Water-Stains 工具链：`probe_pno_jitter.py`（60Hz，`e=0.002`，`k=16`）、`probe_drop_x.py`（单格 90 帧）。

## 1. 整面时间抖动 = 把不该进透镜的场拿去 3-tap

PNO 的有限差分吃的是 **高度场**。谁进 3-tap，谁的空间噪声就会变成法线、再变成整块玻璃在颤。

| 3-tap 输入 | p95 帧间 `|Δn|` | 观感 |
|:---|:---|:---|
| 湿痕带 trail | 0.101 | 整面扫、整面抖 |
| DropMask + 0.25 湿痕（中间态） | 0.046 | 仍明显 |
| 主雨滴 mainDrop（近+远） | 0.020 | 可接受 |
| 仅近层主雨滴 | 0.004 | 最稳 |
| 水雾 StaticDrops（`uv*40`） | 空间 `|n|` 高，帧间 ≈ 0.002 | 空间碎、时间几乎不动 |

水雾空间很吵但时间几乎静止；它进 DropMask 的 3-tap 时，历史故障是 **整面 PNO 噪声**（看起来像磨砂在爬），不是每滴在晃。

锁：

- `MF_WS_Drops.PNOMask = S(0.3, 1, 近层 mainDrop + 远层 mainDrop)`，只此一项。
- `MF_WS_RainField` 的 3-tap **只吃 PNOMask**。中心 tap 的 Mist / TrailMask 只出透明度。
- 列珠串留在 DropMask 里走完整透镜，不进 PNOMask。
- 湿痕只走 `湿痕不透明度`。禁止再把 trail 加回有限差分「显得更湿」。

## 2. 每滴自抖 = 摆动相位绑在会动的量上

Heartfelt 摆动是 `sin(φ + sin(φ))`，`φ` 必须在 **格内稳定**。相位一跟下落走，滑落段每一滴都会左右高频搓。

| `φ` | 单格 90 帧 max `|Δx|`/帧 | 观感 |
|:---|:---|:---|
| 像素 `UV.y * 20` | （空间剪切，不必看时间） | 一滴剪成斜条。已禁。 |
| Saw 下落 `y * 20` | 0.036 | 滑落段每滴自己左右抖。相位跟 `y` 走，一格里 `sin` 要扫好几圈。 |
| 格内 `n.x * 20 + n.z` | **0** | 圆滴，不自抖。`n` 是格种子，格在则相位在。 |

锁：`φ = n.x*20 + n.z`，再 `sin(φ+sin(φ))`。禁止像素 UV，禁止接 Saw 的 `y`。

## 3. 不要再试的假因

- 折射强度 0.3 和 PNO `k=16` 不是这两条抖的根因。改 k / 改 0.3 会换一档畸变，治不好相位和 3-tap 对象。
- `DDX/DDY(WorldPosition)` 在这块半透明 PNO 材质上会直接把视口打死，禁止拿来「平滑」。
- 水雾进 3-tap、湿痕进 3-tap，都是已经量过的错路。
